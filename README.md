# Military Tailor & Sewing Shop — Static Website

A responsive HTML/CSS/JavaScript website template for a military tailoring and sewing shop.

## Important placeholders

The supplied Maps result did not provide enough verified business information for:
- confirmed shop/business name in English
- phone number
- WhatsApp number
- email
- opening hours
- exact service list
- business description
- real photographs
- Google Maps embed code

These are intentionally marked as placeholders rather than invented.

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize

1. Replace the placeholder business name.
2. Add the verified phone/WhatsApp/email.
3. Replace the gallery placeholders with real images.
4. Add the official Google Maps embed iframe if desired.
5. Connect the enquiry form to a backend, Formspree, email service, or WhatsApp.
